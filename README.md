# 핀볼 🎱

스프링으로 공을 쏘고 플리퍼로 쳐 올려 점수를 모으는 핀볼. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나(서버 없이 혼자 하는 게임). `index.html` + `logic.js`(규칙·물리, 화면 없음) + `game.js`(화면·입력·소리)로 이루어져 있습니다. 원작(윈도우 3D 핀볼)의 그림·소리는 쓰지 않고 새로 만들었습니다.

- 300x520 칸 판이 기울어 있어 공이 늘 아래로 굴러 내려온다(중력). 공은 3개이고 아래 구멍으로 빠지면 하나 잃는다
- **발사**: 오른쪽 통로 맨 아래 스프링을 꾹 눌렀다 놓으면 공이 올라간다 (1초까지 당길수록 세다). 약하게 쏘면 통로로 도로 내려와 다시 쏠 수 있다
- **플리퍼** 둘: ◀ ▶ 버튼을 누르고 있거나, 판의 왼쪽·오른쪽 절반을 누르거나, 키보드 Z · / (또는 ←→) 로 올린다. 스페이스(↓)는 발사. 여러 손가락을 동시에 쓸 수 있다
- 난이도: 중력 950, 플리퍼 길이 50. 자동 플레이 모의(버튼 연타·양쪽 동시·타이밍 맞춰 치기)로 공 수명 중앙값이 약 6~19초, 3판 안에 끝나는 정도로 맞췄다
- 점수: 범퍼 100 · 슬링샷 10(빠른 공일 때만 튕겨 줌) · 초록 타깃 500 (켜진 타깃은 50). 타깃 셋을 모두 켜면 +2000 과 **점수 배수 +1** (최대 x5)
- 공이 오래(4초) 멈춰 있으면 살짝 흔들어 준다. 최고 점수는 `pinballBest` (로비 표시용). M 소리
- 물리는 1/240초 단위로 계산해 빠른 공이 플리퍼를 뚫고 지나가지 않는다. 플리퍼 표면의 속도를 공에 더해 세게 칠수록 세게 나간다

시험은 `npm test`(= `node --test`): `test/logic.test.js`(발사 세기·중력·판 밖으로 안 나감·플리퍼 위로 떨어진 공이 안 뚫림·빠른 공이 안 뚫림·플리퍼가 올려 침·범퍼·배수·타깃 보너스·공 잃기와 게임 끝·같은 입력이면 같은 결과).

## 🎯 미션 테이블 (시작 화면에서 고름)
클래식 테이블(위 설명)은 그대로이고, 두 번째 판이 추가됐습니다. **기록은 따로** 저장됩니다(`pinballMissionBest`). 클래식 기록(`pinballBest`)은 로비에 보이는 그대로입니다.
- **범퍼 5개**의 다른 배치. 슬링샷·플리퍼·벽·타깃은 같습니다.
- **미션**: 판 위쪽에 지금 미션과 진행(예: `🎯 범퍼를 맞혀요 0/18`)이 나오고, 차례로 깹니다. 한 바퀴(4개)를 돌면 목표가 40%씩 커집니다.

| 순서 | 미션 | 목표(첫 바퀴) | 보상 |
|---|---|---|---|
| 1 | 범퍼 맞히기 | 18번 | +3000 (점수 배수 적용) |
| 2 | 초록 타깃 3개 모두 켜기 | 1번(2바퀴마다 +1) | 🎱 멀티볼 |
| 3 | 슬링샷 맞히기 | 12번 | +4000 |
| 4 | 플리퍼로 공 쳐올리기 | 22번 | 🎱 멀티볼 |

- **멀티볼**: 추가 공이 오른쪽 위에서 들어옵니다(최대 3개). 추가 공이 빠져도 **공은 줄지 않고**, 메인 공이 빠지면 남은 추가 공이 이어받습니다(HUD 공 수 옆에 `3+1`처럼 표시). 모든 공이 빠졌을 때만 공이 하나 줄어듭니다. 추가 공이 타깃 위 같은 곳에서 4초 넘게 멈추면 메인 공처럼 흔들어 줍니다.
- 구조: `logic.js` 의 `TABLES`(판 배치), `MISSIONS`, `missionHit`·`spawnExtra`·`promote`, 공 하나의 물리 `physics`(메인·추가 공이 같이 씀).

### 균형을 어떻게 맞췄나
- **발견한 문제(고침)**: 처음 배치에서는 가운데 위 범퍼와 위쪽 타깃 사이의 좁은 틈에 공이 끼어 범퍼 100점·타깃 50점을 끝없이 얻는 **점수 놀이터**가 생겼습니다. 범퍼를 벽·타깃·슬링샷·다른 범퍼에서 공 지름+24 이상 떨어뜨리도록 재배치하고, 이 간격을 **시험으로 지킵니다**(`test/logic.test.js`). 무작위로 공을 400번 떨어뜨려 보니 두 테이블의 점수 분포가 비슷했습니다(중앙값 660 vs 910, 99% 14,540으로 같음).
- 플리퍼 타이밍을 맞춰 치는 봇(일부러 놓치는 비율 30%·55%)으로 20판씩 비교. 클래식 한 판 중앙값 647초·점수 약 32만 → 미션 테이블 875초(약 1.35배)·점수 약 91만(약 2.8배), 미션 약 15개·멀티볼 약 7번. 범퍼 배치만으로는 공 수명이 클래식과 비슷하고(18.8초 vs 16.5초) 길어진 건 멀티볼 때문입니다. 별도 모드·별도 기록이라 그대로 뒀습니다.
- 멀티볼 보상이 두 개일 때는 12판 중 6판이 900초 안에 안 끝나서, 플리퍼 미션 보상을 1개로 줄이고 목표를 1.5배로 올렸습니다.
- **봇은 사람보다 훨씬 잘 쳐서 시간의 절대값은 의미가 없고 비교용입니다. 사람이 하는 체감 난이도와 폰 터치 감각은 측정하지 못했습니다.**
